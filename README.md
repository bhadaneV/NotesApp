# 📝 NotesApp (Java Console Application)

A simple text-based **Notes Manager** built using Java and file I/O (`FileWriter`, `FileReader`, and `BufferedReader`). This project allows users to add and view notes via the terminal, with all notes saved to a local text file.

---

## 🚀 Features

- 📌 Add new notes
- 📂 View saved notes
- 💾 Notes are stored in `notes.txt` (persisted locally)
- ✅ Uses `FileWriter` and `BufferedReader` for file handling

---

## 🛠️ Technologies Used

- Java
- File I/O (`java.io` package)
- Scanner for console input
- VS Code + Git + GitHub
